# BizStatus.co.za

Live opening-status directory for South African businesses.

## Pages

- `/` — Home
- `/stores` — Business directory
- `/stores/:slug` — Store detail
- `/pricing` — Plans & FAQ
- `/blog` — Insights & stories
- `/blog/:slug` — Article
- `/contact` — Contact form
- `/privacy` — Privacy Policy
- `/terms` — Terms of Use

## Brand colours

| Token | Hex |
|-------|-----|
| Blue | `#2563EB` |
| Green | `#22C55E` |
| Navy | `#1B2A4A` |

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).
